# Code of Conduct

Interactions in this project's issues and pull requests are about the
work: be direct, be specific, assume good faith.

Security issues follow SECURITY.md; conduct reports go to the maintainer
through the private-advisory channel.

The maintainer is a single person and cannot be a neutral party in a
report about themselves; such reports are handled through GitHub's
Community Guidelines and Terms of Service reporting, which apply to this
repository regardless of this document.
